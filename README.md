# OpenSubLists

OpenSubLists is a simple, self-hostable subscription tracker designed for Cloudflare Workers and D1.

The repository is currently in the pre-implementation planning phase. Start with the [documentation index](./docs/README.md).

## Planned MVP

- Invite-only Cloudflare Access authentication.
- Isolated subscription data per user.
- Accurate recurring billing dates.
- Multi-currency tracking without misleading conversion.
- Responsive English and Simplified Chinese web UI.
- Versioned JSON import and export.

No application code has been scaffolded yet.
